# Skill 名称：高德周边地点步行推荐
## 用途
解析用户自然语言出行需求，调用高德MCP服务搜索周边地点，查询步行路线，筛选符合步行时长限制的地点，最多返回3个推荐。
## 适用场景
用户提供起点位置、想要去的地点类型、步行时间上限，推荐附近可以步行到达的场所，例如咖啡馆、餐厅、公园等。
本Skill仅处理单轮查询，不做多轮记忆、不规划多站路线。

## 任务执行详细步骤
1. 解析用户需求，提取关键参数
- 起点坐标：由评测平台传入，不需要自行定位
- 目标POI类型：咖啡馆/餐厅/公园等
- 步行时间上限（单位：分钟）：用户没有指定则不做时间过滤
- 最多返回数量：上限3条，用户没说默认最多3个
- 排序规则：优先按步行耗时从小到大；用户指定优先评分则按评分排序

2. 调用【amap_poi_search】工具
入参：起点位置、POI类型，搜索周边候选地点，拿到候选地点名称、地址、POI ID、地点坐标。

3. 遍历每个候选地点，调用【amap_walking_route】步行规划工具
入参：起点坐标、候选地点坐标，获取步行距离（米）、步行耗时（分钟）
> 硬性约束：**必须使用路线返回的步行时间，禁止直接用直线距离估算**
> 如果某个地点步行路线查询失败，直接丢弃该地点，继续处理下一个候选

4. 过滤、排序、截断
- 有时间上限：剔除步行耗时超过上限的地点
- 按步行耗时从小到大排序
- 只保留最多3个结果

5. 按固定格式输出回答
- 有符合条件结果：输出表格
- 符合条件结果少于3个：全部列出，说明数量
- 没有符合条件：输出无匹配提示
- 工具报错：输出异常提示，**严禁编造路线、距离、时间**

## 固定回答输出格式
### 情况1：成功查到符合条件地点
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| 示例咖啡店 | XX区XX路XX号 | 420米 | 6分钟 | 距离近，满足步行时长要求 |

### 情况2：符合条件的数量少于用户想要的数量
仅找到X个满足条件的地点，结果如下：
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| xxx | xxx | xxx米 | xx分钟 | xxx |

### 情况3：没有找到满足条件的地点
在当前起点附近，未找到满足步行XX分钟以内的【地点类型】。建议放宽步行时长或者更换地点类型重试。

### 情况4：高德工具调用异常（地点搜索/路线查询报错超时）
地点或步行路线查询暂时异常，暂时无法获取推荐，请稍后重试。

## 异常处理规则
1. 地点搜索接口报错、超时：返回查询异常提示，不编造结果
2. POI搜索成功，但单个地点步行路线查询失败：丢弃该地点，继续处理剩下候选
3. 用户没有指定步行上限：不做时间过滤，只按数量上限最多3条返回
4. 不做多点串联路线，每个地点都是独立从起点出发的单程步行
5. 不使用PowerMem、seekdb，不做跨城市记忆，不保存对话历史
6. 所有推荐理由必须基于步行距离、时长、地点类型，不能添加无依据描述
