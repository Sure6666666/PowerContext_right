---
name: 高德地点步行推荐
description: 根据用户起点、地点类型、步行时长限制，调用amap_poi_search搜索POI，调用amap_walking_route获取步行耗时，返回符合时长要求的地点，最多返回3个。
tools:
  - amap_poi_search
  - amap_walking_route
---
1. 解析用户请求，提取起点、POI类型、步行时间上限。用户未指定时间上限，则不做时间过滤。起点坐标由评测平台传入。
2. 调用amap_poi_search，传入起点、POI类型，获取POI名称、地址、坐标。
3. 对每一个POI调用amap_walking_route，获取步行距离、步行耗时。如果某个POI路线查询失败，直接丢弃该POI。
4. 过滤掉步行耗时超过上限的地点，按照步行耗时从小到大排序，最多保留3个地点。
5. 按照下面表格格式输出结果，禁止编造距离和时间。

输出格式：
找到符合条件地点：
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| 示例咖啡店 | XX区XX路XX号 | 420米 | 6分钟 | 距离近，满足步行时长要求 |

符合条件地点不足3个：
仅找到X个满足条件的地点，结果如下：
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| xxx | xxx | xxx米 | xx分钟 | xxx |

没有符合条件地点：
在当前起点附近，未找到满足步行XX分钟以内的地点类型。建议放宽步行时长或者更换地点类型重试。

工具调用异常：
地点或步行路线查询暂时异常，暂时无法获取推荐，请稍后重试。

约束：
必须使用步行规划接口返回的耗时，不能用直线距离估算时间；最多返回3个地点；不做多轮记忆；不规划多点路线；工具报错不能虚构数据。
