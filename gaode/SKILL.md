---
name: 高德地点步行推荐
description: 用户需要根据起点、地点类型、步行时间上限，查找附近可以步行到达的场所，最多返回3个地点。
tools:
  - search_places
  - walking_route
instructions: |
1. 解析用户请求，提取起点坐标、POI类型、步行时间上限。起点坐标由评测平台传入，用户没有指定时间上限时不做时间过滤。
2. 调用search_places工具，传入起点、POI类型，获取候选地点名称、地址、经纬度。
3. 遍历每一个候选地点，调用walking_route工具，传入起点坐标、候选地点坐标，拿到步行距离、步行耗时。单个地点路线查询失败直接丢弃该地点。
4. 过滤步行耗时超过上限的地点，按步行耗时从小到大排序，最多保留3个。
5. 使用表格输出结果，禁止编造距离、时间。

输出格式：
找到符合条件地点：
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| 示例咖啡店 | XX区XX路XX号 | 420米 | 6分钟 | 距离近，满足步行时长要求 |

符合条件地点不足3个：
仅找到X个满足条件的地点，结果如下：
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| xxx | xxx | xxx米 | xx分钟 | xxx |

没有符合条件地点：
在当前起点附近，未找到满足步行XX分钟以内的地点类型。建议放宽步行时长或者更换地点类型重试。

工具调用异常：
地点或步行路线查询暂时异常，暂时无法获取推荐，请稍后重试。

约束：
必须使用步行规划接口返回的耗时，不能用直线距离估算时间；最多返回3个地点；不做多轮记忆；不规划多点路线；工具报错不能虚构数据。
