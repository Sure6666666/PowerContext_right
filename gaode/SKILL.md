# Skill 名称：高德周边地点步行推荐
## 用途
解析用户自然语言出行需求，调用高德MCP服务搜索周边地点，查询步行路线，筛选符合步行时长限制的地点，最多返回3个推荐，给用户出行参考。
## 适用场景
用户提供起点位置、想要去的地点类型、步行时间上限、推荐数量、排序偏好，需要推荐起点附近可以步行到达的场所，例如咖啡馆、餐厅、公园等。
本Skill仅处理单轮查询，不做多轮记忆、多站路线规划。

## 任务执行详细步骤
1. 解析用户需求，提取关键参数
读取用户原始提问，提取下面信息：
- 起点坐标：由评测平台直接传入，不需要做定位
- 目标POI类型：咖啡馆/餐厅/公园等
- 步行时间上限（单位：分钟）：用户没有指定则不设置时间过滤
- 期望推荐数量：上限最多3条；用户没指定，默认最多3条
- 排序偏好：优先距离近、优先评分高；没有指定默认按步行耗时由近到远排序

2. 调用【高德MCP-地点搜索工具】
入参：起点坐标、POI类型
拿到返回候选列表：地点名称、详细地址、POI ID、地点坐标。

3. 遍历候选地点，逐个调用【高德MCP-步行路线规划工具】
对每一个候选地点，传入起点坐标 + 当前候选地点坐标，请求步行路线。
拿到返回结果：步行距离（米）、预计步行耗时（分钟）。
> 硬性规则：**必须使用路线返回的步行时间，禁止用直线距离估算步行时长**
> 如果某个地点步行路线查询失败，直接舍弃该地点，不纳入候选。

4. 条件过滤与排序
① 过滤：剔除步行耗时超过用户要求上限的地点（有上限时）
② 排序：按照用户给出的偏好排序；无偏好则按步行耗时从小到大排序
③ 截断：最多保留3个地点

5. 组装回答，按固定格式输出
- 有符合条件结果：使用表格输出
- 符合条件数量不足：表格列出能找到的，同时文字说明数量不足
- 工具调用失败 / 没有符合条件地点：如实说明，**严禁编造地点、路线、时间**
- 营业状态、排队情况、安静程度等高德没有返回的信息，统一标注【未核实】

## 固定回答输出格式
### 情况1：成功查到符合条件地点
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| 示例咖啡店 | XX区XX路XX号 | 420米 | 6分钟 | 距离近，满足步行时长要求 |

### 情况2：符合条件的数量少于用户想要的数量
仅找到X个满足条件的地点，结果如下：
| 地点名称 | 地址 | 步行距离 | 预计步行时间 | 推荐理由 |
| ---- | ---- | ---- | ---- | ---- |
| xxx | xxx | xxx米 | xx分钟 | xxx |

### 情况3：没有找到满足条件的地点
在当前起点附近，未找到满足步行XX分钟以内的【地点类型】。建议放宽步行时长或者更换地点类型重试。

### 情况4：高德工具调用异常（地点搜索/路线查询报错超时）
地点或步行路线查询暂时异常，暂时无法获取推荐，请稍后重试。

## 异常处理规则
1. 地点搜索接口报错、超时：返回查询异常提示，不编造结果
2. POI搜索成功，但单个地点步行路线查询失败：丢弃该地点，继续处理剩下候选
3. 用户没有指定步行上限：不做时间过滤，只按数量上限3条返回
4. 不做多点串联路线，每个地点都是独立从起点出发的单程步行
5. 不使用PowerMem、seekdb，不做跨城市记忆，不保存对话历史
6. 所有推荐理由必须基于步行距离、时长、地点类型，不能添加无依据描述
